I want to create a lightweight CAPTCHA solver for the game Margonem that will integrate with an existing JavaScript bot (userscript). The CAPTCHA requires the user to select all buttons containing an asterisk symbol "*" and ignore those with carets "^". The layout of the buttons is a fixed 2x3 grid.

Please implement this solution locally by executing the following steps:

1. ARCHITECTURE & DEPENDENCIES:
- Create a lightweight Python microserver using `Flask` and `Flask-CORS` (listening on port 5000).
- Use `opencv-python` and `numpy` for image processing. Do NOT use machine learning or neural networks (the solution must be ultra-lightweight and run fast on CPU).

2. IMAGE PROCESSING LOGIC (Python):
- The server should expose a POST `/solve` endpoint that accepts a JSON object containing the CAPTCHA image encoded in Base64.
- Decode the Base64 image into an OpenCV-compatible format.
- Since the 2x3 button grid layout is static, geometrically crop/divide the received image into 6 equal sections (one for each button).
- For each section, implement a reliable way to distinguish between the asterisk "*" and the caret "^" shapes. You can achieve this via thresholding (`cv2.threshold`) combined with pixel analysis, contour detection, or Template Matching (`cv2.matchTemplate`) using a pre-cropped template of the asterisk.
- The function must return a JSON response containing an array of indices (e.g., `[0, 2, 3, 4, 5]`) representing the buttons that contain the asterisk.

3. JAVASCRIPT INTEGRATION (Userscript):
- Generate a JavaScript code snippet (or a separate file named `captcha_injector.js`) that can be easily integrated into a Tampermonkey userscript.
- The JS code must:
  a) Detect when the CAPTCHA window appears in the DOM.
  b) Select the CAPTCHA image element, render it onto a hidden `<canvas>`, and convert it to a Base64 DataURL.
  c) Send a POST request with the image data to `http://localhost:5000/solve`.
  d) Upon receiving the array of indices, asynchronously trigger the `.click()` method on the corresponding button elements in the game's DOM, and finally click the "Potwierdzam" (Confirm) button.

Please write the complete server code, the injector script, and provide clear instructions on how to install dependencies and run the project.
